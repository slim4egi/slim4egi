# Структура каталога СТК Метер — версия 2.0

## Верхний уровень
1. Приборы учета
2. Узлы коллекторные
3. Арматура трубопроводная
4. Системы учета энергоресурсов и компоненты АСКУЭ

## Поля товара
- `id` — идентификатор
- `manufacturer` — производитель
- `topCategory` — верхняя категория
- `subCategory` — подкатегория
- `name` — наименование
- `article` — артикул
- `price` — ориентир цены
- `priceType` — `до` или `по запросу`
- `minOrder` — минимальная партия/условие поставки
- `availability` — наличие/статус
- `images` — массив изображений
- `documents` — массив документов (заготовка)
- `description` — описание (заготовка)
- `specifications` — характеристики (объект, заготовка)
- `sourceUrl` / `url` — ссылка на источник производителя
- `tags` — дополнительные метки
