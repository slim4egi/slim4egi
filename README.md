# ООО «СТК МЕТЕР» — каталог

Статический каталог продукции с корзиной-заявкой и Cloudflare Worker API.

## Cloudflare
- Worker: `stkmeter`
- D1: `stk-meter-orders`
- D1 binding: `STK_METER_DB`
- Static assets: `public/`
- API: `POST /api/orders`
- Health check: `GET /api/health`

## Важно
Текст согласия на обработку персональных данных в `public/privacy-consent.html` является рабочим шаблоном и должен быть сверён с фактическими реквизитами, политикой обработки ПДн и внутренними сроками хранения до публикации сайта.
