# ООО «СТК Метер» — каталог оборудования

Каталог приборов учета, узлов, арматуры и компонентов систем учета энергоресурсов.

## Возможности

- каталог продукции;
- поиск и фильтрация товаров;
- фильтрация по производителю и типу оборудования;
- карточки товаров с характеристиками;
- корзина для формирования заявки;
- изменение количества и удаление товаров из заявки;
- сохранение корзины в браузере;
- форма заявки с реквизитами организации и контактными данными;
- обязательное согласие на обработку персональных данных;
- сохранение заявок и состава заказа в Cloudflare D1;
- отправка уведомлений о новых заявках через Resend.

## Структура проекта

- `public/` — сайт и каталог;
- `public/products.json` — каталог товаров;
- `public/app.js` — логика каталога и корзины;
- `public/requisites.html` — реквизиты ООО «СТК Метер»;
- `src/index.js` — Cloudflare Worker и API заявок;
- `wrangler.jsonc` — конфигурация Cloudflare Worker и D1;
- `package.json` — настройки проекта.

## Cloudflare

Worker: `stkmeter`

D1 database: `stk-meter-orders`

D1 binding:

`STK_METER_DB`

## Email уведомления

После сохранения заявки в D1 Worker отправляет уведомление через Resend.

Для Production используются секреты Cloudflare:

- `RESEND_API_KEY` — API-ключ Resend;
- `RESEND_FROM` — подтверждённый адрес отправителя.

API-ключ не должен храниться в GitHub.

Если почтовый сервис временно недоступен, заявка уже сохранена в D1 и не теряется.
